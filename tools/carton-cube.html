What this calculator solves

Use Carton Cube to calculate the external space occupied by one or more identical cartons. CBM means cubic meters (m³); cubic feet are shown as ft³. The result gives both units per carton as well as shipment totals, so a carton specification and a batch space plan can use the same measurements. Box Volume can use internal dimensions for capacity; this tool uses finished external dimensions for occupied space.

How to choose the inputs

Measure the closed carton’s maximum external length, width, and height in one unit and enter the number of identical cartons. Split the calculation when carton sizes differ. Include normal bulge or protrusions when they affect occupied space.

InputHow to prepare it
Carton external lengthMeasure the longest external side of a closed, packed carton, including any bulge or protrusion that changes its occupied envelope. Select inches or centimeters for all three dimensions.
Carton external widthMeasure the second external side of the same finished carton. Convert a millimeter or meter measurement to the selected unit before entering it.
Carton external heightMeasure the remaining external side in the same unit. Do not substitute internal box height or the height of an unpacked product.
Carton countCount the whole, identical-size cartons in this group. Run different carton sizes separately; do not enter product units or an average carton dimension.

How the calculation works

Total cube = length × width × height × carton count
  1. Calculate one carton: multiply its external length × width × height. Inches give in³; centimeters give cm³.
  2. Convert the volume: divide cm³ by 1,000,000 for m³ (CBM), or divide in³ by 1,728 for ft³. One ft³ equals exactly 0.028316846592 m³. These are volume conversions, not dimensional-weight divisors.
  3. Calculate the shipment: multiply the unrounded per-carton volume by the whole carton count. Review both per-carton conversions and the total before combining separate size groups.

Worked example

One 24 × 16 × 12 in carton has 4,608 in³ of external cube: 4,608 ÷ 1,728 ≈ 2.666667 ft³, or about 0.075512 m³ (CBM). Twenty identical cartons total 53.333 ft³ and 1.510 m³. The totals use unrounded per-carton volumes.

Next action: Record each carton size and count separately, sum the group volumes in one cubic unit, then verify pallet layout and any carrier measurement or billing requirements.

How to interpret the result

Use the per-carton m³ or ft³ value for one carton specification and the total for the entered carton count. For mixed-size shipments, calculate each size group separately and add the group totals in the same cubic unit; do not multiply average side lengths. Per-carton conversions display up to six decimal places and totals up to three, so multiplying rounded display values can differ slightly. These are geometric volumes, not a freight quote, billable weight, or a guarantee that the load fits a vehicle or pallet.

Common mistakes

  • Using internal dimensions for external space planning.
  • Combining different carton sizes under one average dimension.
  • Ignoring bulge, straps, or protruding closures.
  • Treating cubic volume as a weight or freight quote.

Assumptions and limitations

The result excludes pallet gaps, aisle space, irregular stacking, orientation constraints, unusable vehicle volume, weight limits, and carrier pricing. It does not guarantee that the cartons tessellate in a given space.

Geometric planning estimate: confirm finished external dimensions and counts on the physical shipment. Cube does not establish billable weight, freight cost, load stability, or usable vehicle capacity.

Related workflow

  1. Before: measure finished external cartons by size group.
  2. After: use Cases per Pallet for a specific footprint and compare total shipment cube.
